## El sitio

Construido con HTML, CSS y JavaScript, sin frameworks ni proceso de compilación. Incluye filtros de proyectos, casos de experiencia en diálogos, trayectoria profesional y contacto.

El diseño se adapta a escritorio y móvil. La navegación admite teclado, los filtros comunican su estado y se respeta la preferencia de movimiento reducido. Las fuentes se cargan desde Google Fonts con alternativas locales de respaldo.

## Desarrollo local

Clonar el repositorio y servir los archivos desde su directorio:

```sh
git clone git@github.com:Edwineverth/edwineverth.github.io.git
cd edwineverth.github.io
python3 -m http.server 8000
```

Abrir [localhost:8000](http://localhost:8000). No requiere instalar paquetes.

## Publicación

GitHub Pages sirve el sitio desde la raíz de la rama `master`:

1. Abrir **Settings → Pages** en el repositorio.
2. Seleccionar **Deploy from a branch**.
3. Elegir **master** y **/ (root)**.
4. Guardar la configuración.

Las siguientes actualizaciones de esa rama se publican en [edwineverth.github.io](https://edwineverth.github.io).
